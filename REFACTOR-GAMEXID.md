# Gamex ID Front — mantenimiento

La interfaz usa Angular y TypeScript. Los servicios consultan la API y los componentes muestran los datos.

Antes de publicar: compilar, ejecutar las pruebas de interfaz y comprobar la API con MySQL. Pedidos requiere los endpoints `/api/orders` del backend y su migración de base de datos.

Gaming City se consulta desde el backend; la credencial permanece en la configuración privada del servidor. La portada contiene una demostración visual, no movimientos reales.

Cada publicación debe conservar la versión anterior para poder revertirla.
